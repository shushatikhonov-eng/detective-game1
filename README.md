# ДЕЛО № 031 — Последний ход

## Что внутри
- `index.html` — веб-приложение: экран телевизора и интерфейс пульта iPhone.
- `firebase-rules.json` — пример правил Realtime Database для тестового запуска.

## Важно про синхронизацию
Один HTML-файл сам по себе не может передавать команды с iPhone на телевизор через интернет. Для этого нужен общий realtime-сервер. В этой версии предусмотрена интеграция с Firebase Realtime Database.

## Быстрый запуск
1. Создайте проект в https://console.firebase.google.com/
2. Добавьте Web App и скопируйте Firebase config.
3. Создайте Realtime Database.
4. В `index.html` найдите `const firebaseConfig = null;` и замените `null` на объект конфигурации из Firebase.
5. Для тестовой вечеринки примените правила из `firebase-rules.json`. ВНИМАНИЕ: эти правила разрешают чтение/запись без авторизации. Используйте их только для временного теста, затем настройте Firebase Authentication и более строгие правила.
6. Загрузите `index.html` на HTTPS-хостинг (например, GitHub Pages, Netlify или свой сайт).
7. Откройте на телевизоре Samsung Internet Browser: `https://ваш-сайт/` (режим TV).
8. Откройте на iPhone: `https://ваш-сайт/?mode=remote` (режим пульта). Введите одинаковый код комнаты и нажмите «Подключиться».

## Текущие ограничения прототипа
- Реализован каркас сценария, главы, карточки материалов, карта и команды пульта.
- Исторические сведения сокращены; перед публичным коммерческим запуском нужна редактура и проверка каждого факта по первичным документам.
- Карта использует OpenStreetMap и приблизительные координаты. Для точной игровой реконструкции нужно отдельно геокодировать и сверить каждую точку.
- В этой версии нет полноценной системы таймера, подсказок по уровням, протокола допросов, журнала найденных улик, автоматического подсчёта очков и финальной проверки логики. Это следующий этап разработки.
- В Firebase-версии для комнаты следует добавить защиту кодом/авторизацией и разделить права TV/remote. Не публикуйте конфигурацию с открытыми правилами в постоянном публичном проекте.
